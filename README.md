# BURPSTACK Personal Portfolio

A simple multi-page personal portfolio website created using HTML only for BURPSTACK Task 01.

## Pages Included
- `index.html` — Home and introduction
- `about.html` — Education, skills, and interests
- `projects.html` — Project descriptions and technology details
- `contact.html` — Contact form demonstration

## Technologies Used
- HTML5

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the other pages.

## Before Submission
- Replace `Your Name` with your name.
- Add your own `profile.jpg` image in the same folder, or change/remove the image element.
- Add your actual GitHub and LinkedIn profile links.
- Replace project links with your real repository links when available.

## What I Learned
I practised HTML document structure, semantic elements, navigation links, images with alternative text, lists, headings, labels, form inputs, and basic accessibility.

## Note
The contact form is only an HTML demonstration. A backend or form service is needed to actually send messages.
